# 2026 世界杯胜平负竞猜 App

朋友内部使用的世界杯竞猜小站。项目只使用不可提现的虚拟积分，不涉及真实金钱、赌博、充值或兑换。

## 功能

- 普通用户登录，账号由管理员预先分配
- 虚拟积分余额、排行榜、个人投注记录
- 单关 / 串关胜平负竞猜
- 服务端校验比赛、赔率、选项和余额，前端传来的赔率不会被信任
- 投注扣分、中奖返奖、积分流水
- 开赛时间到后自动锁盘，禁止继续下注
- 管理员后台：
  - 创建用户
  - 加 / 扣积分
  - 停用 / 启用账号
  - 重置密码
  - 手动修改赔率
  - 手动锁盘 / 解锁
  - 手动录入比分，系统自动判断主胜 / 平局 / 客胜并结算
  - 查看投注、积分流水、操作日志
  - 跳转官方结果页面，方便人工核对
- SQLite 本地持久化
- 密码哈希存储
- Bearer token 登录会话

除“开赛时间到后自动锁盘”之外，赛程、赔率、比分和结算都由管理员人工处理。

## 默认账号

普通体验账号：

- `demo / 123456`
- 登录页展示的其他体验账号密码也都是 `123456`

管理员账号：

- `admin / admin123456`

首次部署后建议立即登录管理员账号，在“我的”页面修改密码。

## 本地运行

```bash
python server.py
```

然后打开：

```text
http://localhost:8000
```

后端只使用 Python 标准库，无需安装 pip 依赖。前端使用 React + Babel CDN，所以浏览器需要能访问 CDN。

## 数据文件

启动后会自动创建：

```text
mockgaming.sqlite3
```

这个文件包含用户、密码哈希、积分、投注、赛果、流水和日志，已经在 `.gitignore` 中排除。部署时要备份这个文件。

## 定时任务

`server.py` 启动后会开启后台定时任务，默认每 60 秒扫描一次比赛：

- 如果当前时间已经超过比赛 `kickoff_ts`
- 且比赛未结算、未锁盘
- 系统会自动锁盘，禁止继续下注

可以通过环境变量调整扫描间隔：

```bash
MOCKGAMING_TASK_INTERVAL=30 python server.py
```

## 部署提示

GitHub Pages 不能运行 Python 后端，也不能写入 SQLite。需要部署到支持 Python 服务的环境，例如 VPS、Render、Railway、Fly.io 等。

上线前至少要做：

- 修改默认管理员密码
- 配置 HTTPS
- 定期备份 `mockgaming.sqlite3`
- 限制后台访问或使用强密码
- 根据真实赛程更新 `wc-data.js` 和 `server.py` 中的比赛数据
